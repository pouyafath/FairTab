# Contributing

Contributions are welcome! Please read the full guide before opening a PR:

→ **[docs/contributing.md](docs/contributing.md)**

Quick checklist:
- [ ] Open an issue first for significant features
- [ ] Use Node.js 20+ and npm 10+
- [ ] `npm run typecheck` passes
- [ ] `npm run lint` passes
- [ ] `npm run test` passes
- [ ] `npm run build` passes
- [ ] PR is focused on one change
